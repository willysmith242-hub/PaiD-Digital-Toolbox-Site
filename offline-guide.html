PaiD Digital Toolbox — Offline Guide

PaiD Tools for all.

Prepare PaiD itself for offline use

  1. Open PaiD Digital Toolbox while connected to the internet.
  2. Wait for the homepage to finish loading and open the calculator tools.
  3. On a supported browser, choose “Install app” or “Add to Home screen” from the browser menu if offered.
  4. Keep the site open briefly so the service worker can cache local pages and files.
  5. Turn off Wi-Fi and mobile data, then reopen the app and test it. If a page fails, reconnect and retry; offline support depends on browser cache and hosting.
  6. Download this guide for reference before going offline.

What is intended to work offline?

  • Cached PaiD homepage, CSS, JavaScript, manifest, icon and offline/software-library pages.
  • Built-in unit converter and percentage calculator, after the site is successfully cached.
  • Software catalogue information already cached in the browser.
  • PDF-to-DXF has a generated local engine bundle (about 2.5 MB) on the build branch. Browser conversion and airplane-mode use still need real tests before it is marked fully operational.

Offline status for every listed app

  • Built into PaiD: the unit converter, percentage calculator and cached catalogue pages are designed to run locally.
  • Installer required: desktop tools such as FreeCAD, LibreCAD, Blender, Inkscape, GIMP, QGIS, KiCad, LibreOffice, VLC, 7-Zip and supported PDF tools must be downloaded and installed for the correct operating system.
  • Commercial / licence check: AutoCAD, AVEVA and other paid engineering tools must be obtained through authorised channels; confirm offline activation rights with the vendor.
  • Online-only / alternative needed: browser CAD viewers, cloud converters, online AI services and hosted apps need internet unless the provider offers an actual offline app. Use a local alternative where possible.

What cannot be promised offline?

  • Third-party online websites, cloud converters, online AI tools, account services, payments, synchronisation and online databases.
  • Installer downloads, software updates and online licence/activation checks.
  • Every commercial program as a prebundled PaiD download. Redistribution depends on each software's licence and vendor permission.
  • Desktop software running directly on an Android phone. Many CAD and engineering programs require a supported Windows, macOS or Linux computer.

Make other software work offline

  1. Open the software library while online.
  2. Download each program from its official vendor source and choose the correct operating system.
  3. Save installers and vendor-provided offline help files to your computer or backup drive.
  4. Install and activate the software as required by the vendor, then disconnect and test the functions you need.
  5. Keep a copy of the installer and a record of its version and licence conditions.

Important: An offline website is not the same as an offline copy of every third-party app. PaiD can make its own lightweight tools offline and provide a catalogue of legitimate installers. We will not bundle paid/proprietary software without permission or claim online-only services work without internet.
