Software library

This catalogue is saved with PaiD's offline pages. Open each official source while online, download the installer for your device, and keep a backup. The links themselves cannot download a program when you have no internet.

Important: PaiD cannot legally bundle every third-party app or commercial engineering package into one download. We link to official sources and will only host installers when the licence permits redistribution. Some software needs Windows/macOS/Linux, substantial storage, paid licences, sign-in, or internet activation. A phone cannot run every desktop engineering program.

Offline rule: downloading an installer is not the same as installing or activating the software. Confirm the vendor's offline/activation policy before relying on it without internet.

Offline availability status

Built into PaiD: the unit converter and percentage calculator run in the browser; cached pages are intended to remain available offline.

Installer required: FreeCAD, LibreCAD, Blender, Inkscape, GIMP, QGIS, KiCad, LibreOffice, VLC, 7-Zip and supported desktop PDF tools can be installed locally. Download from the official source and test offline operation on your device.

Commercial / activation check: AutoCAD, AVEVA E3D and other commercial engineering applications require authorised licences. Availability of offline activation depends on the product and licence.

Online-only unless the vendor provides an offline app: hosted CAD viewers, online converters, cloud AI tools and account-based web apps. PaiD will list a local alternative where practical rather than falsely labelling a cloud service offline.

Scope: PaiD will aim to offer an offline path or clearly identified offline alternative for every tool in the catalogue. It cannot bundle every installer into the website or make internet-dependent services function without a connection.

How to prepare an offline computer

  1. While online, check your operating system, processor type, free storage and licence requirements.
  2. Download the installer only from the official vendor page.
  3. Save it to a clearly named folder such as PaiD-Offline-Installers and copy it to a backup drive if available.
  4. Keep any required licence files, offline help files and checksums from the vendor. Never store passwords or banking PINs in the toolbox.
  5. Install and launch the software while online first if the vendor requires setup or activation. Then disconnect and test the exact features you need.
